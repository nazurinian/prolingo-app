## Findings

### A. Text Global Browser TTS "Reset" visual pulse
- `src/components/text/TextStructuredAudioControls.jsx`: `data-text-reset-global-browser-tts` is a persistent button, with `disabled={disabled || resetDisabled}`.
- `src/App.jsx`: `structuredTextAudioSidebarControls.resetDisabled = !structuredTextResetGuard.allowed || generationRunning`.
- `src/domain/text/textStructuredResetDomain.js`: the reset guard blocks when `textLibraryCommandBusy` is true.
- `src/App.jsx`: Workspace Browser TTS voice/rate edits call `handleTextLibraryStructuredCommand` through `runTextLibraryUiCommand`, which toggles `textLibraryCommandBusy` true/false for the transaction.
- Result: a Workspace voice/rate change can temporarily disable the unrelated Global Browser TTS Reset button. The original `disabled:opacity-40` visibly faded the button, analogous to the accepted App Bar `DOC · PARAGRAPH` pulse.
- Hypothesis limitation: Global Browser TTS voice/rate updates alone directly call `setTextStructuredPreferences` (not the library command), so this specific disabled pulse is **not proven** when changing only the Global rate/voice; it requires a real Chrome observation or DOM mutation trace.

### B. Workspace "1.0×" small speed Reset
- `src/components/text/TextStructuredAudioControls.jsx`: `RateControl` conditionally mounts a small `1.0×` button only when `currentRate !== 1`.
- Crossing exactly 1.0× by dragging the slider mounts/unmounts that button and changes inline geometry. This is a **separate, code-confirmed layout-change mechanism**, independent of global Reset opacity.
- **Not modified in this experiment** to avoid mixing causes.

### C. Edge Download Rate/Pitch and Stale
- `src/components/text/TextStructuredAudioControls.jsx`: Global Edge Download rate/pitch range inputs call `onGenerationPreferencesChange({edgeRate | edgePitch})`.
- `src/App.jsx`: this updates generation preferences via `normalizeTextStructuredAudioGenerationPreferences` (without invoking audio generation or modifying IndexedDB Staging).
- `src/domain/text/textStructuredAudioRenderFingerprintDomain.js`: the render descriptor/fingerprint includes both `rate` and `pitch`.
- `src/domain/text/textStructuredAudioCoverageDomain.js`: mismatched render fingerprint returns `STALE`; restoring a matching profile can return `READY` if the original binary still exists.
- Expected: Card coverage badges/counts and related generate-button eligibility may update; generated MP3 files must **not** be erased or silently regenerated by a slider change.
- `data-text-global-edge-restore-default` has an intentional disabled state when at Sonia/Gadis and 0%/0Hz. Crossing the canonical default legitimately changes its enabled/disabled appearance. Treat this distinctly from unwanted busy-state pulses.

## Experimental patch

One line only, `src/components/text/TextStructuredAudioControls.jsx`:
```diff
- hover:bg-sky-50 disabled:opacity-40 transition-colors
+ hover:bg-sky-50 disabled:opacity-100 transition-colors
```
Applied **only** to `data-text-reset-global-browser-tts`. The `disabled` expression, reset guard, storage, Staging, fingerprints, and Edge coverage logic remain unchanged.
