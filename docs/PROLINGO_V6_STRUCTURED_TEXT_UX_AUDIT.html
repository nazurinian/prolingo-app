1 Executive Summary & Audit Baseline

ProLingo v6 Beta has established an advanced audio playback architecture featuring Split/Full dual-representation modes, dual-channel audio sequencing (English Text and Indonesian Meaning), IndexedDB binary staging, Portable ZIP archives, and hierarchical speaker voice overrides. All existing P9-A automated runtime suites (Split/Full modes, Pause/Resume/Stop, Local First with TTS fallback, and localStorage persistence) pass successfully.

The goal of this independent audit is to identify usability bottlenecks, confusing terminology, nested dropdowns, and card expansion defects, providing an actionable redesign that makes the existing controls intuitive and ergonomic on both desktop and mobile—without modifying or replacing the audio engine.

3 Verified UX Problems & Cognitive Friction Points

3.1. Sudden Card Collapse on Stop (Critical Defect)

Source-Code Verified Defect: In TextStructuredPlayer.jsx (line 159):
const expanded = manualExpanded || isActiveCard || isFocusCard;
When playback is active, isActiveCard is true, auto-expanding the card. When the user hits Stop (or when playback finishes the last segment and stops), isActiveCard immediately switches to false. If the user did not explicitly toggle the card's chevron (meaning manualExpanded === false), the card snaps shut instantly.

Impact: The learner is abruptly ejected from their visual reading context the moment audio stops, losing their place in the paragraph.

3.2. Active Card Indicator Blindness in FULL Representation Mode

Source-Code Verified Defect: In textStructuredPlaybackSessionService.js (lines 264–266):
const suppressHighlight = normalizedRepresentation === TEXT_STRUCTURED_PLAYBACK_REPRESENTATION_MODES.FULL;
setPlayingIndex(suppressHighlight ? null : item.id);
setCurrentIndex(item.id);
In Full mode, playingIndex is forced to null to suppress sentence-level highlighting. However, StructuredPlayerCard determines its active status via segments.find(s => s.id === playingIndex). Because playingIndex is null, isActiveCard evaluates to false for every single card in the document!

Impact: During Full playback, the currently playing card receives no active border, displays no ACTIVE badge, never auto-expands, and fails to auto-scroll into view.

3.3. Disconnected Heading Quick-Play Controls

Inside an expanded Paragraph card (TextParagraphUnifiedReading.jsx), the Text (English) and Meaning (Indonesian) blocks have plain uppercase text headings: <p>Text</p> and <p>Meaning</p> without any action buttons. To listen to only the English paragraph, or only Indonesian, a user must currently change their global or manual preferences in Player Settings, or switch on Split mode and click sentences individually.

3.4. Overuse of Native Dropdowns & Micro-Typography

TextStructuredPlaybackControls.jsx uses heavy micro-typography (text-[7px], text-[8px], text-[9px]). Options with only 2 to 4 choices (Sequential/Shuffle, Continue/Restart, Repeat, Channels) are implemented as native <select> dropdowns, creating high tap friction and visual clutter.

5 Recommended Information Architecture

To resolve confusion between what is heard, what is synthesized, and what is stored, we define a clear 3-Pillar Information Architecture:

🏛️ Diagram 2: The Three Pillars of ProLingo Audio Architecture
1. WHAT IS PLAYED
Playback Engine (Live Output):
  • Representation: Split vs Full
  • Channels: EN, EN→ID, ID→EN, ID
  • Routing: Local First vs TTS Only
  • Local Priority: Sonia > Ryan > Libby
  • Live Browser TTS: Female UK default, independent rates
  • Feel: Delays, Repeat, Order, Resume
2. WHAT IS GENERATED
Edge Synthesis (Background):
  • Service Health: Edge WebSocket check
  • Global Defaults: EN (Sonia), ID (Tuti)
  • Synthesis Tuning: Rate (±50%), Pitch (±20Hz)
  • Presets: Default / Follow Player / Custom
  • Actions: Generate Missing, Regen Card
  • Never changes live playback voice
3. WHAT IS STORED
Storage & Assets (IndexedDB):
  • Staging (IndexedDB): Binary MP3/WAV blobs
  • Portable ZIP: Package import & validation
  • Readiness Status: Ready, History*, Stale, Missing
  • Storage Actions: Clear Staging, Clear Cache
  • Folder: Deprecated & locked in beta.8
Edge Synthesis ➔ Generates MP3s into ➔ IndexedDB Staging
Portable ZIP ➔ Merges Blobs into ➔ IndexedDB Staging
IndexedDB Staging ➔ Feeds Ready Audio to ➔ Playback Engine

6 Paragraph Card Expansion & Active-Card Architecture

6.1. Three First-Class Expansion Modes

We introduce an explicit cardExpansionMode preference with three clear operating modes:

🔄 Diagram 3: Card Expansion State Transition & Persistence Rules
DEFAULT
Follow Playback Active card expands automatically as audio plays
READING
Expand All All cards opened for seamless continuous reading
MANUAL
Custom Expansion governed exclusively by user clicks
The Stop Rule: When playback stops (via Stop button, Pause, or end of list), the currently active card MUST REMAIN EXPANDED. It never snaps shut unexpectedly.
The Manual Transition Rule: If the user manually clicks any card's chevron while in follow-playback mode, the system automatically transitions the document to custom mode so the user's manual intent is preserved.

6.2. Active Card Resolution in FULL Mode

To fix the bug where Full mode renders cards "blind", TextStructuredPlayer.jsx will track activeBlockId at the player level, decoupling card active detection from the sentence-level playingIndex: 

const isActiveCard = playingContext === TEXT_STRUCTURED_PLAYBACK_CONTEXT
  && (isPlaying || isPaused)
  && (block.segments?.some(s => s.id === playingIndex) || block.id === activeBlockId);

Sentence-level background highlighting remains suppressed in Full mode as required by P9-A, while the card properly receives its indigo border, ACTIVE badge, and auto-scroll behavior.

6.3. Quick-Play Controls on TEXT & MEANING Headings

In TextParagraphUnifiedReading.jsx, the TEXT and MEANING block headers are upgraded with single-tap quick-play buttons:

7 Global, Manual, and Voice Inheritance Model

🌳 Diagram 4: Audio Channel & Voice Override Cascade
CHANNEL & REPEAT INHERITANCE:
  1. Global Playback: Sets document sequence (EN/ID order) & repeat.
  2. Card Play ('Card' button): Defaults to "(Follow Global)" or uses explicit card channel mode. Always sequential within the card.
  3. Segment Only ('Only' button): Defaults to "(Follow Global)" or uses explicit segment channel mode. Always Split representation.
  4. Heading Quick-Play: Overrides channel to TEXT_ONLY or MEANING_ONLY for a single run.
VOICE RESOLUTION CASCADE:
  1. Segment Override (if explicit voice assigned)
  2. Speaker Assignment (in conversation cards)
  3. Card Override (card-specific voice assignment)
  4. Document Override (workspace voice assignment)
  5. Global Browser TTS Default (Web Speech API)
